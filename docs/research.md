# TIPI-J NPC 研究与原型的对应关系

作者：高信哲 / Xinzhe Gao。

## 第一阶段 人格保持与漂移

IPSJ 第88届全国大会（2026），讲演号 **5V-03**：

《ゲームNPC対話生成のためのTIPIを用いたパーソナリティモデルの基礎検討》。[官方目录](https://www.ipsj.or.jp/event/taikai/88/WEB/html/program/program4.html)

方法为 TIPI-J 十项设定、反向计分与五维参数计算，再将人格信息转换为角色提示词。DeepSeek-V3 在固定角色设定下生成五名 NPC 的恋爱话题对话，共100组、每组15轮。人工检查500个 NPC—场景样本，385个保持成功，整体成功率为77%。

| 角色 | 保持成功率 |
| --- | ---: |
| Aki | 82% |
| Mika | 74% |
| Yui | 85% |
| Rina | 69% |
| Kana | 75% |

研究观察到中后期的语气与情感表达同质化，以及部分理性、回避型角色共情表达增加。

## 第二阶段 跨模型比较

JSSST 第43届大会（2026），登坛编号 **7a-1-R**：

大会目录题名《TIPI-Jに基づく大規模言語モデルを用いたゲームNPC人格対話生成に関する研究》。[官方程序](https://jssst2026.wordpress.com/program/)

研究在地震后避难情境中，使用相同场景与角色条件比较 DeepSeek、Gemini、Claude。设置五名 NPC，每个模型进行100组实验。按论文方法检查每名 NPC 的15次发话：至少8次符合目标人格，且首次发话没有明显人格矛盾时，判定为一致。

| 模型 | 人格一致率 |
| --- | ---: |
| DeepSeek | 81% |
| Gemini | 85% / 86%（版本差异待核对） |
| Claude | 89% |


## 本仓库新增内容

本仓库包含 PyTorch 六类意图分类、规则回应、进程内会话状态与训练评测，并新增独立 DeepSeek 实时对话、论文目标参数配置及 SQLite 调用记录。实时功能的协议与状态流程已用模拟响应检查，真实账户联调待完成。

| 研究或原型部分 | 输出来源与评测 |
| --- | --- |
| 论文人格对话 | 真实 LLM 生成，由人工评判人格表现 |
| 本仓库玩家意图分类 | 自建语料训练的小型 MLP，输出六类预测及未校准分数 |
| 本仓库 NPC 回应 | 显式规则模板，根据人格参数、分类结果与会话状态生成 |


## 新增实时demo与历史实验的区别

- 场景与交互：以第二篇避难情境为基础的中文玩家—NPC对话；历史实验是多NPC日语讨论，尚未在demo中复现群聊。
- 参数：`configs/jssst2026.json` 原样保留表2公布的0～1目标值，换算到1～7供模型使用。未声称拥有或恢复原始十项问卷。
- N计分：官方手册使用 `(Q4 + 8 - Q9) / 2`。旧原型与六页论文公式方向相反；本次修正新demo的题项计分与重建，未重算历史数据，也不能由此确认原实验代码是否受影响。
- 版本差异：六页最终稿正文报告 Gemini 86%，`修正版_6.docx` 与海报写85%；需从原始统计核实，不合并不同版本结果。
- 观测：保存实际请求、原始回复和错误，不以规则输出冒充模型生成。尚无自动人格评分、模型排名或人格控制优于普通文字人设的证据。
- 新demo使用当前可配置的模型，不能声称复现了论文中的历史模型版本。

计分来源：[TIPI-J 官方尺度手册](https://jspp.gr.jp/doc/manual_TIPI-J.pdf)。
